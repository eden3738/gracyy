# Editable Video Template

This is a responsive profile-page template you can customize with your own wallpaper, Spotify link, colors, and text.

## Where To Add Your Files

- Put wallpapers/images in `assets/wallpapers`
- Update the Spotify link in `template.config.js`
- Put exported videos/screenshots in `exports`

## Quick Edit

Open `template.config.js` and change:

- `title`
- `subtitle`
- `displayName`
- `displayBio`
- `instagramHandle`
- `instagramUrl`
- `spotifyUrl`
- `wallpaper`
- `accentColor`
- `secondAccentColor`

Example:

```js
wallpaper: "./assets/wallpapers/my-wallpaper.jpg",
spotifyUrl: "https://open.spotify.com/track/..."
```

## Preview

Open `index.html` in your browser. You can also use the preview controls on the right side to test a wallpaper or song without editing the config.

## Export Tip

Open the page in a desktop or mobile-sized browser window. It will change layout automatically.
